# Generated Python contract artifacts

Generated by `pnpm contracts:gen`; do not edit by hand. This shared tree is consumed by solver-side Python and is staged in the generator export map.

`validator.py` uses `jsonschema` Draft 2020-12 schemas for all 19 canonical contract kinds and the four authoring-input schemas. `canonical.py` validates the RFC 8785 I-JSON domain, emits JCS bytes, and computes SHA-256. `canonical_hash()` accepts already materialized canonical payloads; SI normalization, defaults, and PresetRef expansion remain consumer responsibilities.

Runtime: Python 3.12 and `jsonschema` 4.x. `codegen-index.python.v1.json` is the authoritative 19+4 coverage inventory. QoI-shaped identifiers are contract data under ADR-006 D8-2, not new verification claims.

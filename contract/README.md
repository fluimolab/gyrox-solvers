# Gyrox contract exchange

This tree is generated by the main Gyrox repository with `pnpm contracts:gen`. It contains generated TypeScript/Ajv/OpenAPI/Python artifacts, source JSON Schemas, and the complete contract fixture set.

`MANIFEST.sha256` exists only in `gyrox-solvers/contract/`; its bytes are the canonical `path\0sha256\n` preimage. C# validators remain main-only; Python validators are shared for solver consumption. Files in this tree use the MIT license designation in the solvers repository `LICENSE`.
